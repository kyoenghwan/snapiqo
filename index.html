Windows용 캡처·녹화 엔진을 만들고 있습니다. 준비되면 이 자리에서 받을 수 있습니다.

웹 캡처 확장(Chrome)

웹 페이지는 화면과 함께 실제 글자·색·글꼴·CSS selector를 담아 앱으로 보냅니다. 입력한 값과 비밀번호는 넣지 않습니다.

확장 내려받기(.zip)

휴대폰이나 태블릿에서는 설치할 수 없습니다. 컴퓨터에서 이 페이지를 열어 내려받으세요.

찍고, 고치고, 비교하고, 넘깁니다

업무 시스템처럼 소스 구조를 읽을 수 없는 화면도 이미지에서 글자와 상자를 찾아 레이어로 나눕니다.

1 캡처

필요한 만큼만 찍기

영역·창·화면, 마우스를 올린 요소, 끝까지 내려 붙이는 스크롤 캡처, 시스템 소리와 마이크를 담는 녹화.

⌥⇧1 영역 ⌥⇧2 창 ⌥⇧3 화면 ⌥⇧4 요소 ⌥⇧5 녹화 1080p30
2 레이어

글자와 버튼을 따로 고치기

이미지 속 글자 줄과 버튼·입력란을 레이어로 찾아, 옮기고 글자·크기·색을 바꿉니다. 고치지 않은 곳은 원본 그대로입니다.

텍스트 “로그인” 14px 세미볼드 버튼 채움 #2563EB 입력란 테두리 #9CA3AF
3 비교

AS-IS / TO-BE

원본과 수정본을 나란히 보고, 바뀐 것을 문장으로 확인합니다.

글자 “로그인” → “시작하기” 위치 +40, 0px 채움색 #2563EB → #111111
4 AI 전달

폴더 하나로 넘기기

원본·수정본·변경 내역·요소 정보·지시문을 한 폴더에 만들고, AI에게 붙여 넣을 프롬프트를 복사합니다.

instructions.md original.png modified.png changes.json elements.json styles.json

그리고

웹 페이지는 DOM 그대로

Chrome 확장으로 찍으면 추정 대신 페이지의 실제 값이 들어갑니다. AI 전달 묶음에는 요소마다 CSS selector와 계산된 CSS가 붙습니다.

  • 잘려서 안 보이는 글자, 편집 중인 입력은 빼고 담습니다
  • 주소는 query 없이 도메인과 경로만

AI 앱이 직접 씁니다

Claude Code 같은 AI 앱이 MCP로 연결해 캡처·화면 읽기·녹화를 요청합니다. 앱에서 승인한 범위 안에서만 동작합니다.

  • 앱별 승인 범위·만료·회수
  • 화면 조작은 매번 확인 또는 끄기

이 컴퓨터 밖으로 보내지 않습니다

캡처, 글자 인식(OCR), 레이어 분석은 모두 이 컴퓨터에서 합니다. 서버에 올리지 않습니다.

  • 가림은 원본 픽셀까지 지운 뒤 저장
  • 비밀번호 입력란의 값은 읽지 않음

macOS에 설치하기

  1. DMG를 열고 SNAPIQO를 응용 프로그램 폴더로 끌어 놓습니다내려받은 SNAPIQO.dmg를 더블 클릭합니다.
  2. 처음 열 때 한 번 허용합니다“확인할 수 없는 개발자” 안내가 뜨면 닫은 뒤, 시스템 설정 › 개인정보 보호 및 보안 아래에서 SNAPIQO의 그래도 열기를 누릅니다.
  3. 화면 기록을 켭니다처음 캡처할 때 묻는 창에서, 또는 시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 녹음에서 SNAPIQO Capture를 켭니다. 요소 캡처·스크롤 캡처에는 손쉬운 사용도 필요합니다.
  4. (선택) 웹 캡처 확장을 붙입니다확장 zip을 풀고, Chrome 주소창에 chrome://extensions를 연 뒤 개발자 모드를 켜고 “압축해제된 확장 프로그램 로드”로 그 폴더를 고릅니다. 그다음 SNAPIQO 설정 › Chrome 확장 연결에서 연결 설치를 누르면 캡처가 앱으로 바로 들어옵니다.

내려받은 파일 확인

터미널에서 아래 명령의 결과가 내려받기 칸의 SHA-256과 같으면, 받는 동안 바뀌지 않은 파일입니다.

shasum -a 256 ~/Downloads/SNAPIQO.dmg
